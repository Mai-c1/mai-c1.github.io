# 格式化输入输出

## 基本用法

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int x, y;
    scanf("%d%d", &x, &y);   // 读入 x 和 y
    printf("%d\n%d", y, x);  // 输出 y，换行，再输出 x
    
    printf("hello,world");// printf也可以直接输出内容
    return 0;
}
```

注意`scanf`和`printf`是C语言中的输入和输出

- `scanf` 对应 `cin`，变量前面需要加 `&`符号
- `printf` 对应 `cout`



## 类型标识符

类型标识符的作用是**将要输入的值按照指定的格式输入**

```c++
int n;
scanf("%d",&n);// 明确输入的内容会是一个整数
printf("%d",n);
```

| 数据类型 | 格式符 |
| :------- | :----- |
| `int`    | `%d`   |
| `float`  | `%f`   |
| `double` | `%lf`  |
| `char`   | `%c`   |
| `char[]` | `%s`   |

✨**需要注意的是，字符数组的输入和输出方式比较特别**

- 输入时只需要写数组名,不需要写 &
- 输出时也只需要写数组名，就能把整个字符数组输出

```c++
char str[105];
scanf("%s",str);
printf("%s",str);
```



## 格式控制符

printf的%d格式符应用：

| %d格式符 | 说明             |
| :------- | :--------------- |
| %md      | 右对齐输出m位    |
| %-md     | 左对齐输出m位    |
| %0md     | 位数不足m位时补0 |

printf的%f格式符应用：

| %f格式符           | 说明                                                   |
| :----------------- | :----------------------------------------------------- |
| %m.nf              | 总位数m（含小数点），n位小数，右对齐                   |
| %0m.nf             | 总位数m（含小数点），n位小数，右对齐，位数不足m位时补0 |
| %-m.nf             | 总位数m（含小数点），n位小数，左对齐                   |
| **%.nf（最常用）** | 输出保留 **n** 位小数；                                |

```cpp
#include<bits/stdc++.h>
using namespace std;
int main()
{
    int a=12;
    printf("%d\n",a);    //12
    
    float b=3.1415;
    printf("%3.2f\n",b); //3.14
    
    char c='A';
    printf("%c\n",c);	 //A
    
    double d=3.1415;
    printf("%.3lf\n",d); //3.142
    return 0;
}
```



## 区别

两者不是“二选一”，而是“按需使用”。

1. `cin/cout`属于C++ 的`iostream`库，`scanf/printf`源自C语言`stdio.h`库
2. **cin 效率比 scanf 低很多**，尤其输入数据达到 20 万以上时非常明显，在 100 万时 cin 读入就会超时，也推荐用 `'\n'`去替代`endl`。
3. cin 、 cout 能够**自动识别变量**的数据类型， scanf、printf 在输入输出时需要**指定数据类型**。scanf/printf和cin/cout的区别。



`cin/cout`的优势是简单易用，`scanf`/`printf`的优势是高性能、格式控制灵活
