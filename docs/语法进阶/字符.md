# 字符

## 陈彧

字符类型 `char`

常量用单引号括起来，双引号：字符串

ASCII编码（美国信息交换标准代码）128个字符

```c++
char d = '/n'; cout<<d; <-换行
```

开头字符：①48 =>0 ②65=>A ③97=>a            整数->字符 `cout<<(char)a`

`a = getchar();` <= 输入 `putchar(a)` <= 输出         区别:会读入空格(cin不会)

转义字符：（特殊含义->普通输出） -> `\`  如 `\0`、`\t`
