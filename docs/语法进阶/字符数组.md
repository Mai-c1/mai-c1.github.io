# 字符数组

> 字符数组，就是字符+数组

### 定义格式

```c++
char a[100];
```

创建了一个类型为 `char`的一维数组

### 初始化

方式一，在大括号里依次填写

```c++
char a[5] = {'a','b','c'}
```

没有初始化的字符，默认变成整数0，整数0在ascii码表里对应的是`'\0'`，也就是空字符



方式二，使用字符串初始化

```c++
char a[5] = "abc"
```

这种方式会默认在末尾多加一个 `'0'`，需要注意空间大小是否足够



### 字符数组的输入方式

方式一，使用for循环一个个输入**（不常用）**

```c++
char a[105];
int n;
cin>>n;// 如果题目告诉你长度为n
for(int i=1;i<=n;i++){
	cin>>a[i];
}
```

方式二，使用cin一次性输入**（常用）**

```cpp
char a[105];
cin>>a;
```

cin的后面只需要写一个数组名，就可以把完整的字符串读入

方式三，使用cin.getline**（输入带空格的字符数组）**

格式：cin.getline(数组名，数组长度)

```c++
char a[105];
cin.getline(a,105);// 与数组定义保持一直
```

#### 注意点🎈

使用cin和cin.getline输入的字符数组，下标默认从0开始





### 输出

方式一，使用for循环**（不常用）**

方式二，cout后面紧跟数组名

```c++
char a[105];
cin>>a;
cout<<a;
```



### 常用函数

| 函数                         | 功能                                                         | 范例                                                         |
| :--------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| 求字符串长度函数 strlen(s)   | 返回字符串的长度（即结束符之前的字符数目）                   | char a[10]="hello"; int len=strlen(a); //len 为 5            |
| 字符串比较函数 strcmp(s1,s2) | 比较字符串 s1 和 s2，如果相等返回 0；如果 s1<s2，返回负数；如果 s1>s2，返回正数 | char a[10]="hello"，b[10]="world"; <br />int c=strcmp(a,b); //此时 c 的值为负数 |
| 字符串拼接函数 strcat(s1,s2) | 函数将字符串 s2 连接到 s1 的末端，并返回 s1 的地址           | char a[20]="hello"，b[10]="world"; <br />strcat(a,b);<br /> cout<<a; //此时 a 字符数组中存放 helloworld |
| 查找子串函数 strstr(s1,s2)   | 返回字符串 a 中首次出现子串 b 的地址，如果未找到则返回 NULL  | char a[10]="hello"，b[10]="el"，c[10]="eo"; cout<<strstr(a,b); //输出 ello <br />cout<<strstr(a,c); //输出 NULL(空) |
